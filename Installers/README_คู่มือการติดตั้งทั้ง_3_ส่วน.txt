===============================================================================
  คู่มือการติดตั้ง RemoteDesk V1 ทั้ง 3 ส่วน (Windows 10 / 11 64-bit)
  ** ทุกชุดเป็นแบบ Self-Contained (ไม่ต้องลง .NET Runtime เพิ่มในเครื่องอื่น) **
===============================================================================

ภายในโฟลเดอร์ d:\remote desktop\Installers แบ่งออกเป็น 3 ชุดพร้อมไฟล์ .ZIP:

-------------------------------------------------------------------------------
1. [1_Server_Setup] — สำหรับ "เครื่องเซิร์ฟเวอร์กลาง" (Control Server & Relay)
-------------------------------------------------------------------------------
   - วิธีติดตั้ง: คลิกขวาที่ไฟล์ "INSTALL_SERVER.bat" -> เลือก "Run as administrator"
   - สิ่งที่ตัวติดตั้งทำให้:
     * คัดลอกไฟล์ไปไว้ที่ C:\RemoteDesk\Server
     * เปิดพอร์ต Windows Firewall 5100 (API) และ 52100 (Relay) อัตโนมัติ
     * สร้างทางลัดบนหน้าจอ Desktop ("RemoteDesk Server") และตั้งให้รันอัตโนมัติเมื่อเปิดเครื่อง
     * เริ่มรันระบบ Server ทันที

-------------------------------------------------------------------------------
2. [2_Operator_Setup] — สำหรับ "เครื่องคอนโทรล / แอดมิน" (Operator Client)
-------------------------------------------------------------------------------
   - วิธีติดตั้ง: ดับเบิลคลิกไฟล์ "INSTALL_OPERATOR.bat"
   - สิ่งที่ตัวติดตั้งทำให้:
     * ถาม IP ของเครื่องเซิร์ฟเวอร์ (กด Enter เพื่อใช้ค่าเริ่มต้น 192.168.1.110)
     * คัดลอกโปรแกรมไปไว้ที่ C:\RemoteDesk\Operator
     * สร้างไอคอน "RemoteDesk Operator" บนหน้าจอ Desktop
     * เปิดโปรแกรมรีโมทพร้อมโหลดรายชื่อเครื่องขึ้นมาทันที

-------------------------------------------------------------------------------
3. [3_Agent_Setup] — สำหรับ "เครื่องปลายทางที่จะถูกรีโมท" (Remote Agent)
-------------------------------------------------------------------------------
   - วิธีติดตั้ง: คัดลอกโฟลเดอร์ 3_Agent_Setup (หรือแตกไฟล์ 3_Agent_Setup.zip)
     ไปไว้ที่เครื่องปลายทาง แล้วคลิกขวา "INSTALL_AGENT.bat" -> "Run as administrator"
   - สิ่งที่ตัวติดตั้งทำให้:
     * ถาม IP ของเครื่องเซิร์ฟเวอร์ (กด Enter เพื่อใช้ค่าเริ่มต้น 192.168.1.110)
     * คัดลอกโปรแกรมไปไว้ที่ C:\RemoteDesk\Agent
     * เปิดพอร์ต Windows Firewall 52000 (Direct LAN 60 FPS + ส่งไฟล์ + ก๊อปปี้ข้อความ)
     * ตั้งค่าให้รันอัตโนมัติทุกครั้งที่เปิดเครื่อง Windows (Startup)
     * เริ่มทำงานและออนไลน์ขึ้นบนหน้าจอเครื่องคอนโทรลทันที
===============================================================================
