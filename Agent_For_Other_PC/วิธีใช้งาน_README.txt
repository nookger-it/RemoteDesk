================================================================================
  คู่มือการนำ Agent ไปรันที่คอมพิวเตอร์เครื่องอื่นในวง LAN (RemoteDesk V1)
================================================================================

1. สิ่งที่ต้องมีบนคอมพิวเตอร์เครื่องปลายทาง (เครื่องที่ 2, 3, ...):
   - ระบบปฏิบัติการ Windows 10 หรือ Windows 11 (64-bit)
   - ติดตั้ง .NET 10 Runtime (หรือ .NET 10 SDK)
   - เชื่อมต่ออยู่ในวง LAN เดียวกันกับเครื่องแม่ข่าย (IP เครื่องแม่ข่ายปัจจุบัน: 192.168.1.110)

2. วิธีนำไปใช้งานที่เครื่องปลายทาง:
   ขั้นตอนที่ 1: ก๊อปปี้โฟลเดอร์ "Agent_For_Other_PC" ทั้งโฟลเดอร์ (ใส่ Flash Drive หรือแชร์โฟลเดอร์ผ่าน LAN)
               ไปวางไว้ที่เครื่องปลายทาง (เช่น วางไว้ที่หน้าจอ Desktop)
   ขั้นตอนที่ 2: ที่เครื่องปลายทาง ให้คลิกขวาที่ไฟล์ "เริ่มทำงาน_Agent_เครื่องปลายทาง.bat"
               แล้วเลือก "Run as administrator" (หรือดับเบิลคลิกเปิดตามปกติ)
   ขั้นตอนที่ 3: หน้าต่างสีดำ 2 หน้าต่างจะเปิดขึ้นมา:
               - หน้าต่างที่ 1: RemoteDesk Agent Interactive (52000) -> ดูแลการจับภาพหน้าจอและเมาส์/คีย์บอร์ด
               - หน้าต่างที่ 2: RemoteDesk Agent Service -> ลงทะเบียนชื่อเครื่อง (Hostname) เข้าไปที่แม่ข่าย

3. วิธีรีโมทจากเครื่องแม่ข่าย (192.168.1.110):
   - เปิดโปรแกรม "RemoteDesk Operator Client" บนเครื่องแม่ข่าย
   - กดปุ่ม "Refresh"
   - ชื่อคอมพิวเตอร์เครื่องที่ 2 จะปรากฏขึ้นมาในช่องรายชื่อเครื่อง (สถานะ Online)
   - เลือกชื่อเครื่องที่ 2 แล้วกดปุ่ม "Connect (LAN)" เพื่อดูหน้าจอและควบคุมข้ามเครื่องได้ทันที!

4. กรณีเลข IP ของเครื่องแม่ข่ายเปลี่ยน:
   - คลิกขวาที่ไฟล์ "เริ่มทำงาน_Agent_เครื่องปลายทาง.bat" -> เลือก Edit (แก้ไขด้วย Notepad)
   - แก้ไขบรรทัด: set REMOTEDESK_SERVER_IP=192.168.1.110 ให้เป็นเลข IP จริงของเครื่องแม่ข่าย
